# Donor Registration Form

React + Vite implementation for SCRUM-20, SCRUM-21, SCRUM-22 and SCRUM-23.

## Features

- Full name, age and phone number
- Blood group dropdown: A+, A-, B+, B-, O+, O-, AB+, AB-
- City/location field
- Last donation date picker
- Required-field indicators
- Real-time validation states
- Success/error borders and messages
- Disabled Submit Registration button when required fields are invalid
- Responsive desktop, tablet and mobile layout
- Touch-friendly controls
- No external UI library required

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Test

Test at:
- Desktop: 1440px, 1280px, 1024px
- Tablet: 768px
- Mobile: 390px, 360px

Check in Chrome, Edge, Firefox and Safari.

# blood-donor-finder

## About the Project

Blood Donor Finder is a web-based application developed as a Scrum/DevOps project.

The system helps users register as blood donors, search for suitable blood donors based on blood group, and submit blood requests.

## Features

- User Registration and Login
- Donor Registration
- Blood Group Search
- Blood Request
- Admin Management
- Notifications
