# blood-donor-finder

## About the Project

Blood Donor Finder is a web-based application developed as a Scrum/DevOps project.

The system helps users register as blood donors, search for suitable blood donors based on blood group, and submit blood requests.

## Features

- User Registration and Login
- Donor Registration
- Blood Group Search
- Blood Request
- Admin Management
- Notifications
